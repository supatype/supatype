# Examples

Which one to read depends on what you are trying to find out.

| | What it is | Read it for |
|---|---|---|
| **[kitchen-sink](kitchen-sink/)** | One project, two front ends: a marketing site an editor publishes and an app an attendee signs in to | The tour. Nearly every feature, each screen and route saying what it proves |
| [blog](blog/) | A small Next.js blog | A starter to copy. Server rendering, publishing and rich text, without the rest |
| [supabucks](supabucks/) | A loyalty-card SPA served by Supatype itself | `app.mode = "static"`: one command, one origin, no CORS |
| [expo-auth](expo-auth/) | Expo + React Native | Native auth: Secure Store sessions, PKCE OAuth, deep links |
| [edge-kit](edge-kit/) | Vite app plus a functions kitchen sink | Edge functions: env injection, auth gates, service-role writes, webhook HMAC |
| [realtime](realtime/) | Node scripts, no UI | Realtime proven rather than assumed: `postgres_changes`, broadcast, presence, each with a deadline |
| [validation](validation/) | CLI only, Studio as the UI | The three ways to refuse a value, and why they are not interchangeable |
| [self-host](self-host/) | Compose fixture | `supatype self-host compose up`, minted keys, proxy mode |

**Start with `kitchen-sink`** if you want to see what the platform does. Start with `blog` if you
want something small enough to copy into your own project today.

## Which of these are asserted

An example that only compiles proves less than it looks. These run against a live stack in CI:

- `realtime`, `validation`, `kitchen-sink`, `blog`, `supabucks` — see `tests/integration/scripts/`
- everything here is typechecked and, where it has a front end, built on every pull request

The live-stack jobs are dispatch-gated until the images they need are published; each job says
which condition it is waiting on.

## Coverage

[`COVERAGE.md`](COVERAGE.md) is generated by `pnpm coverage:examples`: what the packages export
against what the examples import. It reports rather than gates — whether a given surface deserves
an example is a judgement — but CI fails if it is out of date, so a new export shows up in a diff
where someone decides.

It measures imports, not execution: a name imported and never called still counts. Proving an
example *runs* is what the live-stack jobs are for.
