Changelog

What changed in each Supatype release, in short. Every pull request is listed on GitHub releases.

0.7.0

27 October 2026

  • Supatype knows what it owns. supatype adopt takes over a table a push refused, --release hands it back, and --reclaim takes a released one again. Studio has a Schema objects view of all of it.
  • supatype doctor shows drifted, conflicting and released objects, and --rebaseline starts the record afresh.
  • Safer pushes. A push asks before it puts back access changed outside Supatype, and offers to declare a rename before it asks to drop data. A change that rewrites a whole table needs your consent.
  • Realtime delivers deletes with the old row, judged by the same read rules as everything else.
  • Auth providers are set with auth.providers in the config.
  • Studio gains a Realtime Inspector for self-hosted stacks.
  • Secrets and the database URL no longer appear on any child process's command line.

0.3

23 September to 2 October 2026

  • Publishing, drafts and versions for content models.
  • Functions run concurrently, with their logs.
  • Storage moves to SeaweedFS.
  • Model caches. A model can declare a cache, and a push refuses one that cannot be served.
  • Vue, Svelte and Solid reach parity with React.
  • A model can set its own Studio labels (0.3.6).

0.2

2 to 3 September 2026

  • Supatype's own auth replaces GoTrue in the CLI, the client and Studio.
  • A push refuses a schema that the database engine in use cannot enforce.

Releases before 0.2 are on GitHub releases.
