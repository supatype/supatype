Postgres

PostgreSQL 17 with the extensions an app needs, our own extensions, and safe defaults. It is the database under every Supatype project. Use it on its own too. Open source under the PostgreSQL License, for linux/amd64 and linux/arm64.

Run it

terminal
docker run -d \
  --name supatype-postgres \
  -e POSTGRES_PASSWORD=your-password \
  -p 5432:5432 \
  supatype/postgres:17-latest

The default superuser is supatype_admin, set with POSTGRES_USER.

Our extensions

  • pg_keyspace: Redis, inside your Postgres.
  • pg_topics: Kafka topics, with no broker to run. Not in the image yet.
  • pg_guard: Superuser features, without the superuser.
  • supatype_mask: Hide a column per row, not per table.

Safe defaults

  • Row level security is on by default.
  • Passwords are stored as scram-sha-256.
  • The ordinary postgres role is not a superuser.
  • A table you make by hand in public is not granted to anon or authenticated until you grant it.
  • pg_guard loads on every connection, so roles can manage extensions without SUPERUSER.
  • A failed migration stops the container, so no client reaches a half-migrated database.

Migrations run on first boot and on every start after, so pulling a newer tag over an existing volume applies what is new. supatype migrate doctor checks that the important ones took effect.

Tags

TagWhat it is
supatype/postgres:17-latestThe newest PG17 release. Moves only when a release is tagged.
supatype/postgres:x.y.zOne release, pinned and never changed.
supatype/postgres:latestThe same image as 17-latest.
supatype/postgres:developThe newest build of the develop branch.

Not using Docker? Each release also ships native archives for Linux, macOS and Windows, and the image runs under CloudNativePG. The supatype/postgres repository covers both.
